# TrueRespi 0.1.0

TrueRespi 是面向小鼠、大鼠全身体积描记（WBP）呼吸波形的中文分析与行为标注软件。它把原始呼吸录制、波形浏览、人工标注、模型预标注、呼吸指标统计、Excel 导出和设备录制裁剪放在同一个桌面工作台中。

> 本仓库仅发布 Windows 安装包、更新清单和中文文档，不包含源代码。

## 下载与安装

最新版本：**0.1.0**

- 安装包：`TrueRespi-0.1.0-Setup.exe`
- 校验文件：`SHA256SUMS.txt`
- 更新清单：`update/manifest.json`

安装步骤：

1. 下载安装包并核对 SHA256。
2. 双击安装，阅读并接受中文许可协议。
3. 选择安装目录（默认当前用户目录，无需管理员权限）。
4. 安装完成后从开始菜单或桌面快捷方式启动。

支持覆盖安装：新版本会沿用原安装目录，保留 `%APPDATA%\TrueRespi` 中的项目配置、偏好和日志。

系统要求：Windows 10/11 x64，建议 8 GB 以上内存，约 2 GB 可用磁盘空间。

## 主要功能

### 波形工作台

- 打开 TXT、CSV、TSV、EDF、BDF、MKT、HDF5、NPZ 录制。
- 分块加载与显示金字塔，长录制打开后仍可流畅缩放和平移。
- 滚轮平移、Ctrl+滚轮缩放时间轴、Shift+滚轮缩放 Y 轴。
- 多通道堆叠、通道显示/隐藏、增益、偏移、线宽、抗锯齿、网格和桥接间隙设置。
- 缩略图、卡尺、框选、矩形缩放、时间基准（相对/绝对）、书签。

### 行为标注

- 五个模型分类标签和三个 sigh 事件标签。
- 拖选后按快捷键标注，支持撤销/重做、拆分、删除、修改标注者。
- 标注检查器显示时间、时长、来源、置信度、阈值判断。
- 左侧标注统计按行为显示段数、累计时长和占录制时长比例。
- 支持保存/打开 `.truerespi` 项目，兼容旧版 `.deeprespi` 项目和旧版行为标注 Excel 导入。

### 模型预标注

软件只保留 4 个正式 Pneuma 呼吸行为模型，实验模型、中间网格模型和已停用集成模型不会出现在选择列表中。

| 模型 | 定位 | 说明 |
|---|---|---|
| **Falcon · 推荐模型** | 默认推荐 | 综合表现最均衡，适合常规小鼠 WBP 录制 |
| **Heron · 快速模型** | 快速筛查 | 103 维呼吸特征，CPU 推理速度快 |
| **Osprey · 深度模型** | 复杂模式 | 多分支深度模型，资源占用相对较高 |
| **Swift · 轻量模型** | 批量预标注 | 体积小、启动快，适合大批量处理 |

- ONNX 推理在后台运行，状态栏显示读取、加载模型、推理、整理标注和写入阶段。
- 有兼容 DirectML 的显卡时可加速，无显卡时自动使用 CPU。
- 推理结果作为一组可撤销标注写入，界面不锁定。
- 模型描述统一使用正式中文文案，不显示训练实验、内部网格或临时合规备注。

### 呼吸指标与导出

- Ti、Te、PIF、PEF、TV、EV、MV、RT、IF50 等呼吸指标。
- 逐呼吸、逐秒、逐分钟指标表。
- 行为标注 Excel：统计汇总、Sheet1、sigh 表、1/3/5/10 分钟分窗、30 分钟分段、指标说明、图表。
- PDF 报告、标注 CSV、记录文件 CSV/EDF/HDF5/NPZ、当前视图 PNG。
- 导出在后台执行，进度显示在底部状态栏；输出路径默认与录制文件同目录，可点击文件夹按钮另存。

### 录制裁剪

- MKT 裁剪：手动区间、绝对时间区间、每小时、每 X 分钟。
- LabChart `.adicht` 裁剪：通过官方 SDK 读取，导出 TXT/EDF/HDF5。
- 输出 TXT 保留 emka 头、CRLF、6 位小数和源录制时间偏移。
- 支持多线程并发写出，适合数小时录制。

## 更新机制

软件启动后会静默检查 `update/manifest.json`：

- 有新版本时，夜间模式按钮旁的检查更新按钮显示小箭头。
- 同一版本只自动提示一次。
- 发现新版本后自动在后台下载安装包，下载过程中显示进度。
- 更新窗口提供版本号、发布日期、分节更新说明、项目地址和 SHA256。
- 下载完成后校验 SHA256，再启动 Inno Setup 安装程序。
- 安装程序使用固定 AppId 和原安装目录，支持覆盖安装，无需先卸载。
- 覆盖安装保留 `%APPDATA%\TrueRespi` 中的用户数据。

也可以随时点击顶栏检查更新按钮手动检查。

## 文件与数据

| 内容 | 默认位置 |
|---|---|
| 用户配置、最近文件、更新状态 | `%APPDATA%\TrueRespi` |
| 日志 | `%APPDATA%\TrueRespi\logs` |
| 项目文件 | 用户保存时选择，扩展名 `.truerespi` |
| 导出文件 | 默认与录制文件同目录 |

卸载程序会保留 `%APPDATA%\TrueRespi`，避免误删用户数据；如需彻底清除，请手动删除该目录。
