# TrueRespi 0.5.2

中文界面与启动行为修复版。安装版可直接覆盖 0.5.1（同 AppId，保留用户设置）。

## 下载

| 版本 | 文件 |
|---|---|
| 安装版 | `TrueRespi-0.5.2-Setup.exe` |
| 免安装版 | `TrueRespi-0.5.2-win64-portable.zip` |
| 校验 | `SHA256SUMS.txt` |

## 新功能

- 默认界面语言改为中文（「跟随系统」仍可在偏好设置中选择）。
- 帮助菜单恢复「欢迎向导」手动入口；启动时自动引导只显示一次。

## 改进

- **Qt 标准按钮中文化**：安装版此前未携带 Qt 翻译文件，确定/取消/关闭、向导按钮等显示英文；
  现随包携带 `qtbase_zh_CN/zh_TW`，按应用语言装载，并在切换语言时热替换。
- **补齐缺失词条**：插件管理器、模型管理、偏好设置等 35 个键此前缺失（界面显示英文键名），
  现已补齐中英文翻译。
- 行为标签在波形标注框、右键菜单、趋势表、图表图例中显示中文名（运动/理毛/嗅探/平静呼吸/睡眠），数据键保持英文以兼容模型与导入导出。
- **Excel 附加表样式共享**：25 小时录音的「呼吸指标_每秒」表建表 48.4s → 6.6s（约 7.4×），
  该表写入阶段峰值内存 857MB → 659MB（−198MB）；styles.xml 与各工作表 XML 与改造前逐字节相同。
- **导出性能与流畅度**：呼吸标志比对改二分定位（25 小时场景约 1285×）；指纹重采样分块
  （4500 万样本峰值 −210MB）；导出线程最低优先级并每 200 行让出 GIL，导出期间界面更流畅。

## 错误修复

- 打开 MKT 文件、框选一段并标注后，「行为导出 / 全部数据导出」菜单恒灰；
  右键标注、项目恢复、AASM 标注后的同类问题一并修复。
- 「全部数据」导出在默认设置下缺少「呼吸指标_每秒 / 呼吸指标_每分钟」两张表。
- 启动引导重复弹出：自动弹出后立即持久化关闭标记（无需勾选「不再显示」）；
  保存偏好设置不再把该标记重置为 True。
- 新版本更新提示同一版本只自动弹出一次（手动「检查更新」不受限）。
- 验证报告对话框中文化：分类页签、表头、按钮、提示与校验消息不再显示英文；
  AASM 规则「修复孤立 REM」、自定义绘图「窗口长度」、功率谱「对数」等文案中文化。
