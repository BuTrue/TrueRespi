# TrueRespi 0.5.0

首个公开发布版本，提供 Windows 10/11 64 位安装版与免安装版。

## 下载

| 版本 | 文件 |
|---|---|
| 安装版 | `TrueRespi-0.5.0-Setup.exe` |
| 免安装版 | `TrueRespi-0.5.0-win64-portable.zip` |
| 校验 | `SHA256SUMS.txt` |

## 亮点

- Pneuma 五类呼吸行为模型，支持 DirectML GPU 加速与 CPU 回退。
- 标注/分析双模式；启动默认标注模式，右上角显示当前模式。
- 分析模式统一左栏：文件信息、概览、通道指标；参数通道可按需打开。
- 呼吸指标泳道平滑曲线、左侧指标名、零间距；支持逐呼吸与窗口均值口径。
- 新增「全部数据 Excel」：行为标注 + 每秒呼吸指标 + 每分钟呼吸指标。
- 应用内检查更新；安装版可下载并校验后运行安装程序。
- 内置正式化帮助文档；关于页包含版本、许可、联系邮箱与项目主页。

## 注意事项

- 2026-10-25 已重新上传全部资产：修复了打包版启动即崩溃的问题（构建工具链缺陷），并补齐「自定义工具栏」「命令面板」两个插件模块。请以当前发布页的 SHA256 为准。
- 安装包未做商业代码签名，Windows SmartScreen 可能提示“未知发布者”。请确认下载来源并使用 `SHA256SUMS.txt` 校验。
- 免安装版请解压到可写目录后运行，不要在压缩包内直接双击。
- 本版本暂时关闭鼠标左键框选模型预测；一键分析与键盘活动框流程仍可用。
- 升级前建议备份 `.truerespi` 项目与导出结果。
