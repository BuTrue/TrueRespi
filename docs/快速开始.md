# 快速开始

本页用 5 分钟完成一次最小工作流：打开录制 → 查看波形 → 标注一段行为 → 导出。

## 1. 打开录制

启动 TrueRespi，点击顶栏「打开录制」，或按 `Ctrl+O`。

支持 TXT、CSV/TSV、EDF/BDF、MKT、HDF5、NPZ 和 `.truerespi` 项目。

首次打开长录制时，状态栏会显示显示金字塔构建进度；构建完成后缩放更流畅。

## 2. 查看波形

- 滚轮：左右平移。
- `Ctrl + 滚轮`：缩放时间轴。
- `Shift + 滚轮`：缩放纵轴。
- 中键拖拽：平移视口。
- 左键拖拽：框选时间区间。
- 右上角「适应窗口」：显示整段录制。

## 3. 标注行为

1. 在左侧「行为标签」中选择标签，或直接按对应快捷键。
2. 在波形上拖选时间区间。
3. 松开后生成一条标注。
4. 在「标注检查器」中查看开始、结束、时长、来源和置信度。
5. 使用 `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。

左侧「标注统计」会按行为显示段数、累计时长和占录制时长比例。

## 4. AI 预标注（可选）

1. 确认已打开真实录制。
2. 在顶栏「AI 预标注」旁选择模型，默认 Falcon。
3. 点击「AI 预标注」或按 `F6`。
4. 在状态栏查看推理进度。
5. 完成后结果作为一组可撤销标注写入。

## 5. 保存项目

点击顶栏「保存」或按 `Ctrl+S`。首次保存会要求选择 `.truerespi` 项目路径。

项目文件保存标注、标签、视图设置等；原始录制仍保留在原位置。

## 6. 导出

点击顶栏「导出」，可导出：

- PDF 报告；
- 行为标注 Excel；
- 标注 CSV；
- 记录文件 CSV / EDF / HDF5 / NPZ；
- 当前视图 PNG。

输出路径默认与当前录制同目录。点击路径右侧文件夹按钮可另存。导出在后台执行，进度显示在底部状态栏。

## 7. 裁剪 MKT / LabChart

点击顶栏「裁剪与导出」，或使用「工具」菜单中的 MKT / LabChart 入口。

可选择手动区间、绝对时间、每小时或每 X 分钟，输出 TXT / EDF / HDF5。
