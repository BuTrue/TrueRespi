# 模型说明

TrueRespi 0.1.1 只发布以下 4 个正式 Pneuma 呼吸行为模型。实验网格模型、中间模型和已停用集成模型不会出现在模型选择器中。

## 模型列表

| 模型 | 界面定位 | 适用场景 | 运行特点 |
|---|---|---|---|
| **Falcon** | 推荐模型 | 常规小鼠 WBP 呼吸行为预标注 | 深度模型，综合表现均衡 |
| **Heron** | 快速模型 | 快速筛查、低配置电脑、批量处理 | 基于 103 维呼吸特征，CPU 推理快 |
| **Osprey** | 深度模型 | 复杂呼吸模式、与历史深度模型结果对比 | 多分支深度模型，资源占用较高 |
| **Swift** | 轻量模型 | 大批量快速预标注 | 体积小、启动快 |

## 如何选择

- 不确定时使用 **Falcon**。
- 电脑配置较低或需要快速预览时使用 **Heron**。
- 呼吸模式复杂、需要深度模型对照时使用 **Osprey**。
- 需要批量处理大量录音、追求速度时使用 **Swift**。

## 运行要求

- 模型随安装包发布在 `models` / `models_onnx` 目录。
- 推理通过 ONNX Runtime 执行。
- 有兼容 DirectML 的显卡时可加速；无显卡或初始化失败时自动使用 CPU。
- 推理在后台运行，状态栏显示阶段与进度，界面不会锁定。

## 输出

模型输出五个行为类别：

- moving
- grooming
- sniff
- eupnea
- sleep

结果会按连续时间段合并为标注，并以一组可撤销标注写入当前项目。

## 说明

- 模型只用于科研数据分析辅助，不构成临床诊断或治疗建议。
- 模型输出应结合人工复核使用。
- 不同模型对同一段录制的分类可能不同，这是正常现象。
