# 常见问题

## 安装与启动

**安装时提示缺少 WebView2。**  
安装 Microsoft Edge WebView2 Runtime 后重试。Windows 10/11 通常已内置。

**SmartScreen 提示“未知发布者”。**  
当前安装包未使用商业代码签名证书。请用 `SHA256SUMS.txt` 校验安装包，确认来源后再运行。自签名证书不会让公开用户默认信任。

**覆盖安装后模型不可用。**  
确认安装目录下存在 `models` 和 `models_onnx`，并检查杀毒软件是否误删模型文件。可重新运行安装包修复。

**卸载后重新安装，项目还在吗？**  
项目文件由用户保存，卸载不会删除；用户配置默认保留在 `%APPDATA%\TrueRespi`。

## 打开与波形

**打开 MKT 很慢。**  
首次打开需要读取索引并解码数据；长录制会花费一些时间。之后打开会更快。

**波形太密或太疏。**  
用 `Ctrl + 滚轮` 缩放时间轴，用 `Shift + 滚轮` 调整纵轴，或使用右上角增益档位。

**Y 轴缩不小。**  
Y 轴范围为 0.05–20 倍；如果已经到下限，继续向下滚不会变化。

**左键拖选时视图会移动吗？**  
不会。左键框选只延伸选区，视口保持不动；中键拖拽用于平移。

## 标注与项目

**按标签快捷键没有反应。**  
确认已打开录制、当前没有在输入框中输入，并先拖选一个时间区间。

**导入旧版行为 Excel 失败。**  
请确认工作簿是行为标注表，而不是逐呼吸指标表。软件会在错误提示中说明缺少哪些行为列。

**项目文件能打开，但原始录制找不到。**  
项目只保存标注和设置，录制路径仍指向原文件。请把原始录制放回原路径，或在打开项目后重新指定录制。

## 模型

**模型列表很少。**  
0.1.0 只保留 Falcon、Heron、Osprey、Swift 四个正式模型，实验模型和中间模型不会显示。

**推理很慢。**  
首次加载模型需要时间；长录制推理时间更长。可尝试 Heron 或 Swift，或在支持 DirectML 的显卡上运行。

**推理失败。**  
检查模型目录、ONNX Runtime 和显卡驱动；错误提示会给出具体阶段。

## 导出

**导出的 Excel 没有数据。**  
行为标注 Excel 需要至少一条行为标注；逐秒/逐分钟指标需要勾选“包含逐秒/逐分钟呼吸指标”。

**导出时界面卡住。**  
导出在后台运行，对话框会立即关闭。进度显示在底部状态栏；如果进度长时间不动，请查看日志。

**输出路径在哪里？**  
默认与当前录制同目录；点击路径右侧文件夹按钮可另选。

## 裁剪

**LabChart 文件无法裁剪。**  
当前只处理第一个 Record，并要求通道采样率一致。请在 LabChart 中拆分记录或按通道导出。

**TXT 时间码和源文件不一致。**  
导出保留源录制站点时间偏移；可在 TXT 参数中调整“首行偏移（ms）”。

## 更新

**更新按钮没有小箭头。**  
说明当前版本不低于更新清单版本。可点击按钮手动检查。

**自动下载失败。**  
检查网络和代理；也可以手动打开更新窗口重试，或从 Releases 下载安装包。

## 日志与反馈

日志位于 `%APPDATA%\TrueRespi\logs`。

反馈：https://github.com/BuTrue/TrueRespi/issues
