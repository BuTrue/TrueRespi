# 数据格式与兼容性

## 支持打开

| 格式 | 扩展名 | 说明 |
|---|---|---|
| emka IOX 文本 | `.txt` | 兼容 `Site-time` 表头、制表符/逗号分隔、CRLF |
| CSV / TSV | `.csv` `.tsv` | 首行表头，时间列 + 通道列 |
| EDF / EDF+ | `.edf` | 欧洲数据格式，支持多通道 |
| BDF | `.bdf` | 24 位 EDF 变体 |
| MKT | `.mkt` | emka 原始录制，直接读取、分析和裁剪 |
| HDF5 | `.h5` `.hdf5` | 本软件导出布局 |
| NumPy 归档 | `.npz` | 本软件导出布局 |
| TrueRespi 项目 | `.truerespi` | 标注、标签、视图设置 |

## 录制打开行为

- TXT / CSV 先读取头部和稀疏索引；长录制在后台建立显示金字塔。
- MKT 按 OLE2 流与 zlib 块读取，不会一次解压整段录制。
- EDF / BDF 读取信号头和数据记录。
- HDF5 / NPZ 读取原始通道和元数据。
- 打开大文件时，状态栏显示构建进度；构建期间仍可查看已加载部分。

## 旧数据兼容

- 支持打开旧版 `.deeprespi` 项目。
- 支持导入旧版行为标注 Excel（`.xlsx` / `.xlsm` / `.csv`）。
- 兼容此前导出的标注 CSV 列结构。
- 支持旧版 TXT / EDF / MKT / HDF5 录制。

导入行为标注 Excel 时，软件会把它作为一次可撤销的批量写入；不会修改原始 Excel 文件。

## 导出格式

| 格式 | 适用场景 |
|---|---|
| TXT（emka IOX） | 与 emka IOX 交换，保留源站点时间偏移 |
| EDF | LabChart 等电生理软件交换 |
| HDF5 | 本软件后续打开、程序化处理 |
| NPZ | Python / NumPy 处理 |
| CSV | 通用表格查看、脚本处理 |

TXT 输出保留 emka 表头、CRLF、6 位小数和源录制时间偏移。

## LabChart `.adicht` 限制

- 通过官方 `ADIDatIOWin64.dll` SDK 读取。
- 当前只处理**第一个 Record**。
- 如果第一个 Record 内通道采样率不一致，会明确报错，不会静默丢弃数据。
- 多 Record 或混合采样率文件请先在 LabChart 中拆分记录或按通道导出。

## 文本编码

- 推荐 UTF-8。
- emka IOX 文本按 UTF-8 读取；无法解析时请转换为 UTF-8 再打开。
- 标注 CSV 导出为 UTF-8 BOM，Excel 可直接打开中文。

## 时间与采样率

- 所有内部时间以秒为单位。
- 时间轴支持相对时间和绝对时间。
- 绝对时间来自录制头部的起始时间；缺失时只显示相对时间。
- 不同通道采样率不一致时，呼吸指标使用流量通道的采样率。
