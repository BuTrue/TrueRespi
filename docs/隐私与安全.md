# 隐私与安全

## 本地处理

TrueRespi 默认在本机处理：

- 原始录制文件；
- 标注数据；
- 项目文件；
- 呼吸指标与导出结果。

软件不会主动把原始录制、标注内容或分析结果上传到作者服务器。

## 网络访问

软件只在以下情况访问网络：

1. 检查更新：访问公开的 `update/manifest.json`；
2. 下载更新：从 GitHub Releases 下载安装包；
3. 打开项目主页、发布页面或问题反馈页面：使用系统默认浏览器。

更新检查请求只包含常规 HTTP 信息，不包含用户的原始数据或标注内容。

## 用户责任

- 请自行备份重要项目、录制和导出文件。
- 请确保对导入的数据享有合法权利。
- 请遵守所在机构关于实验动物、人类受试者、临床数据和个人信息保护的规定。
- 不要把包含敏感信息的项目文件或截图上传到公开 Issue。

## 安装包校验

发布页提供 `SHA256SUMS.txt`。安装前建议核对：

```powershell
Get-FileHash .\TrueRespi-0.1.0-Setup.exe -Algorithm SHA256
```

## 代码签名

当前安装包未使用商业代码签名证书。自签名证书只适合内部实验室，需要用户手动信任，不能替代 CA 证书。

详见 [代码签名说明](../代码签名说明.md)。

## 漏洞与安全问题

如发现安全问题，请通过 GitHub Issues 联系，并避免在公开内容中披露敏感数据。
