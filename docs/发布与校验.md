# 发布与校验

本页面向发布维护者，说明 TrueRespi 安装包从构建到 GitHub Release 的流程。

## 1. 版本号

以下文件必须一致：

- `VERSION`
- 根目录 `Cargo.toml`
- `apps/desktop/ui/package.json`
- `apps/desktop/src-tauri/tauri.conf.json`

当前版本：`0.1.1`。

## 2. 构建前端与 release

在仓库根目录：

```powershell
cd apps\desktop
& ".\ui\node_modules\.bin\tauri.cmd" build --no-bundle --ignore-version-mismatches
```

产物：

```text
target\release\truerespi-desktop.exe
```

## 3. 准备安装目录

安装目录：

```text
D:\exe项目\TrueRespi-0.1.1\
```

包含：

- `staging\TrueRespi.exe`
- `staging\truerespi.exe`（CLI）
- `staging\truerespi-mcp.exe`（MCP stdio 服务）
- `staging\onnxruntime.dll`
- `staging\models\`（正式模型）
- `staging\models_onnx\`（正式模型）
- `TrueRespi.ico`
- `TrueRespi.iss`
- 中文许可、安装说明、使用说明、命令行与 Agent、README、CHANGELOG

只打包正式模型：Falcon、Heron、Osprey、Swift，以及 Sigh 事件模型。

## 4. 生成安装包

```powershell
& "C:\Users\True\AppData\Local\Programs\Inno Setup 7\ISCC.exe" "D:\exe项目\TrueRespi-0.1.1\TrueRespi.iss"
```

输出：

```text
D:\exe项目\TrueRespi-0.1.1-Setup.exe
```

## 5. 计算 SHA256

```powershell
Get-FileHash .\TrueRespi-0.1.1-Setup.exe -Algorithm SHA256
```

更新：

- `SHA256SUMS.txt`
- `update/manifest.json` 的 `sha256`
- `update/manifest.json` 的 `editions.ai.sha256`
- `update/manifest.json` 的 `editions.standard.sha256`

## 6. 发布 GitHub Release

```powershell
gh release create v0.1.1 "D:\exe项目\TrueRespi-0.1.1-Setup.exe" "D:\exe项目\TrueRespi-release\SHA256SUMS.txt" "D:\exe项目\TrueRespi-release\install.ps1" `
  -R BuTrue/TrueRespi `
  --title "TrueRespi 0.1.1" `
  --notes-file "D:\exe项目\TrueRespi-release\release-notes-v0.1.1.md" `
  --latest
```

如果 Release 已存在，使用 `gh release upload ... --clobber` 更新附件。

## 7. 更新清单

清单地址：

```text
https://raw.githubusercontent.com/BuTrue/TrueRespi/main/update/manifest.json
```

清单包含：

- `version`
- `release_date`
- `download_url_windows`
- `sha256`
- `release_notes_zh`
- `release_notes_en`
- `min_required_version`
- `editions.ai` / `editions.standard`

## 8. 发布前检查

- 安装包 SHA256 与清单一致；
- Release 附件大小与本地一致；
- 安装包可静默安装；
- 覆盖安装可用；
- 安装后版本号正确；
- 软件能启动并打开真实录制；
- 更新窗口显示“已是最新”或正确的新版本；
- 仓库 Contributors 只有 BuTrue；
- 文档、许可协议、第三方组件说明齐全。

## 9. 代码签名（可选）

如需签名：

```powershell
D:\exe项目\sign-release.ps1 `
  -PfxPath "D:\exe项目\certs\TrueRespi-CodeSigning.pfx" `
  -PfxPassword "<证书密码>"
```

签名后必须重新计算 SHA256，并更新 Release 与更新清单。

公开分发建议使用 OV/EV 代码签名证书，不建议使用自签名证书。
