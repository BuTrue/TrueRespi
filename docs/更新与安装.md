# 更新与安装

## 安装包

最新安装包：

https://github.com/BuTrue/TrueRespi/releases/latest

文件：

- `TrueRespi-<版本>-Setup.exe`：Windows 安装包
- `SHA256SUMS.txt`：安装包校验值
- `install.ps1`：命令行下载、校验、静默安装与卸载脚本

## 全新安装

1. 下载安装包。
2. 可选：核对 SHA256。
3. 双击运行。
4. 阅读并接受中文许可协议。
5. 选择安装目录；默认当前用户目录，无需管理员权限。
6. 安装完成后启动。安装程序会把安装目录下的 `bin` 子目录加入当前用户 PATH，新开终端后可运行 `truerespi --version`。

## 覆盖安装

TrueRespi 使用固定 AppId 和固定安装目录，支持直接覆盖安装：

1. 保存当前项目并退出软件。
2. 双击新版本安装包。
3. 安装程序识别已有版本并沿用原目录。
4. 点击“安装”。
5. 用户数据保留在 `%APPDATA%\TrueRespi`。

建议覆盖安装前备份重要项目。

## 自动更新

软件启动约 3.5 秒后静默检查更新：

1. 发现新版本时，顶栏夜间模式按钮旁的检查更新按钮显示小箭头。
2. 同一版本只自动提示一次。
3. 安装包自动在后台下载，状态栏和更新窗口显示进度。
4. 下载完成后校验 SHA256。
5. 点击“立即安装并覆盖旧版本”启动安装程序。

也可以随时点击顶栏更新按钮手动检查。

## 更新说明

更新窗口按以下结构展示：

- 新增
- 改进
- 修复
- 注意事项

更新窗口不会显示内部清单 URL、缓存路径或调试字段。

## 校验安装包

PowerShell：

```powershell
Get-FileHash .\TrueRespi-0.1.1-Setup.exe -Algorithm SHA256
```

将输出与 `SHA256SUMS.txt` 比对。若不一致，请勿安装并重新下载。

## 静默安装

适合实验室批量部署：

```powershell
TrueRespi-0.1.1-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

指定目录：

```powershell
TrueRespi-0.1.1-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DIR="D:\Program Files\TrueRespi"
```

安装程序会维护当前用户 PATH（指向安装目录下的 `bin` 子目录）；已打开的终端需要重新打开才会生效。

静默安装不会显示许可协议页面；使用即表示已阅读并同意随安装包附带的许可协议。

## 命令行安装（install.ps1）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/BuTrue/TrueRespi/main/install.ps1 | iex"
```

指定版本与目录：

```powershell
.\install.ps1 -Version 0.1.1 -InstallDir D:\Apps\TrueRespi
```

卸载：

```powershell
.\install.ps1 -Uninstall
```

## 卸载

Windows 设置 → 应用 → TrueRespi → 卸载。

卸载默认保留 `%APPDATA%\TrueRespi` 中的用户配置和日志；如需彻底清除，请手动删除该目录。

## 数据位置

| 内容 | 位置 |
|---|---|
| 用户配置、最近文件、更新状态 | `%APPDATA%\TrueRespi` |
| 日志 | `%APPDATA%\TrueRespi\logs` |
| 项目文件 | 用户保存时选择，扩展名 `.truerespi` |
| 导出文件 | 默认与录制文件同目录 |
